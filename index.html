Chưa có file PDF? Xem cách đổi (rất nhanh)

Word, PowerPoint, Excel trên máy tính: bấm File, chọn Lưu thành (Save As) hoặc Xuất (Export), rồi chọn PDF. Cách này giữ đúng bố cục, tránh nhảy trang.

Google Docs / Google Slides: bấm Tệp, chọn Tải xuống, rồi chọn PDF.

Ảnh hoặc file trên điện thoại: vào một trang đổi miễn phí, chọn file, bấm chuyển, rồi tải PDF về:

  • Ảnh sang PDF
  • Word sang PDF
  • PowerPoint sang PDF

Tài liệu riêng tư (giấy tờ, hợp đồng) nên đổi bằng Word hoặc Google Docs, không tải lên web khác. Không làm được thì mang file tới quán, nhân viên sẽ giúp.
